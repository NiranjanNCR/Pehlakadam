# React + TypeScript + Vite — Pehlakadam Portal

Comprehensive Career Counseling, Psychometric Assessment Suite, LMS Learning Portal, and Admin Governance Platform.

## Quick Start

```bash
# Run Development Server
npm run dev

# Run Production Build
npm run build

# Start Production Server
npm start
```

For complete architectural details, database schemas, and admin workflows, refer to [DEVELOPMENT_DOCUMENTATION.md](./DEVELOPMENT_DOCUMENTATION.md).
